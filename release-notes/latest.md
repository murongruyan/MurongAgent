# MurongAgent 1.37

## 1.37 / 26080301 — 2026-08-03

本文件只记录当前待发布版本 1.37 的更新说明，不包含已经发布版本的历史变更。

### Added

- **双端离线朗读与语音输入**：Android 与 Desktop 均可安装离线中文朗读模型（MeloTTS，下载约 159 MB）与流式语音识别模型（Zipformer 中英标点版，下载约 128 MB）；完全本地运行，不依赖系统语音引擎，不上传任何音频。助手回复旁新增朗读按钮，输入框旁新增麦克风按钮。
- **计划模式重做**：复杂任务会自动先生成完整执行计划；计划卡片始终内联在聊天中并默认收起成小卡片，不再用全屏弹窗遮挡模型输出。用户先验收计划，可点“修改计划”让模型按反馈重新生成，确认后再点“执行”。
- **目标模式闭环**：顶栏大标签改为紧凑目标条，可编辑、暂停、恢复、完成；模型能通过 `[goal:start]`、`[goal:update]`、`[goal:pause]`、`[goal:resume]`、`[goal:complete]`、`[plan:start]` 控制标记自主开启 / 更新 / 暂停 / 恢复 / 完成目标和请求计划。说“开个目标模式… / 目标模式开始干吧”会自动进入目标模式。
- **项目页新建文件与新建文件夹**：项目文件树工具栏新增“新建文件”“新建文件夹”按钮，带名称校验，创建后自动刷新目录、展开并打开新文件。
- **扩展环境开发工具自愈**：终端扩展环境缺 python / pip / git / clang 等常用开发命令时，会自动 `pkg install` 安装并重试一次，失败时给出明确提示；PRoot 版本化 symlink（python → python3.14）在非交互 shell 中也能正确解析。
- **系统环境接入真实 Termux 工具**：设备安装了 Termux 时，其 `bin` 目录会自动追加到系统 PATH，python / pip / clang 等可直接被 Agent 与编辑器使用。
- **桌面端语音设置页**：新增“朗读与语音输入”设置卡片，可安装 / 删除 TTS 与 ASR 模型，显示运行时与模型状态、SHA-256 与安全说明。

### Changed

- **模型切换修复**：切换聊天框下方或设置页中的模型时，会同步更新活动中继的 model，不再出现“切换了但实际请求仍是旧模型”的情况。
- **Android 朗读体验**：恢复流式合成边生成边播放，点击后首声明显更快、句间不再停顿；release 压缩下通过 keep 规则保留流式回调的 JNI 反射签名，修复 release 包点朗读即闪退的问题。
- **桌面端朗读范围**：朗读只读助手回复正文，不再把“朗读 / 从此处分叉 / 回退到此处”等操作按钮文字一并读出来。
- **桌面端麦克风交互**：麦克风按钮移到发送按钮旁，点击开始、再点结束并转文字，不再需要长按；静音约 2.5 秒自动停止；识别结果自动填入输入框。
- **朗读模型校验**：SHA-256 以官方固定值校验，官方重新打包时会回退到官方 checksum 清单，不再因单一硬编码值卡死安装。
- **发布流程**：GitHub Release 资产上传改经 origin、Release 同步只同步资产元数据，修复部分环境上传不稳定。

### Fixed

- 修复聊天框下方模型有时无法切换的问题（活动中继 model 未同步）。
- 修复项目页缺少新建文件 / 新建文件夹入口的问题。
- 修复编辑器“运行”按钮提示需要下载 python，但实际报 `exec: python: not found`（退出码 127）的问题。
- 修复 Agent 与编辑器用不上终端扩展或系统 Termux 里已安装 python 等环境的问题。
- 修复 Android release 包点击朗读闪退（R8 拆箱导致 JNI 反射 `invoke([F)Ljava/lang/Integer` 失败）的问题。
- 修复桌面端朗读把操作按钮文字一起读出来的问题。

### Security

- 语音模型与运行时均从官方 Release 下载并校验 SHA-256；录音只在本机识别期间存在，识别完成后临时音频立即删除，不上传。

- Android 单元测试、Debug / Release 构建通过；release DEX 验证流式 TTS 回调签名保留。
- Desktop `go test`、`go vet`、前端构建与 Wails release 打包通过。
- GitHub Actions 将重新生成 1.37 全平台产物，把本文件同步到 GitHub Release 和后端更新说明，并分别上传 Android 主程序与终端扩展。
