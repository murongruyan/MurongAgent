# MurongAgent 1.39

## 1.39 / 26082001 — 2026-08-20

本文件只记录当前待发布版本 1.39 的更新说明，不包含已经发布版本的历史变更。

### Fixed

- **手机端计划模式对齐电脑端**：计划模式开启或复杂任务自动计划时，发送消息不再直接弹出计划卡片；模型会先以只读方式检查项目文件、搜索并理解相关代码，再输出一份可执行、可验证的步骤计划，用户确认后才执行；普通 API 与 Codex 后端路径均生效。
- **计划卡片可滚动、按钮不被遮挡**：修复计划卡片展开后内容过长无法下滑、底部“取消 / 分叉会话 / 执行”等按钮被计划内容挡住的问题；计划详情在卡片内独立滚动，操作按钮固定在卡片底部始终可见。

### Changed

- 手机端计划模式发送路径改为完整 agent 调查循环，移除发送后直接调用计划生成接口的旧入口。
