# MurongAgent 1.40

## 1.40 / 26082002 — 2026-08-20

本文件只记录当前待发布版本 1.40 的更新说明，不包含已经发布版本的历史变更。

### Fixed

- **电脑端聊天框"模型与运行参数"菜单点选失效**：点击"后端与连接 / 模型 / 推理深度"类别或具体选项时，菜单立即关闭、无法选择。根因是点击内部会重建列表、把被点节点从 DOM 移除，随后冒泡到 `document` 的"外部点击关闭"处理器，把已分离的节点误判为外部点击而关闭菜单；现已在菜单内部操作处阻止事件冒泡，外部点击关闭行为保持正常。

### Changed

- 电脑端版本号 1.39 → 1.40（Android `versionCode 26082002`），桌面端 `desktopAgentVersion` 与 Wails `productVersion` 同步升级。
